# Kalkulator Biaya Umroh Mandiri 2026: Mutawwifmu

Sistem simulasi dan kalkulator estimasi biaya Umroh Mandiri & Backpacker 2026 secara transparan, akurat, dan interaktif dengan identitas visual resmi [Mutawwifmu](https://mutawwifmu.com).

## 🚀 Fitur Utama
1. **7 Komponen Perhitungan Biaya**:
   - Visa Umrah & Asuransi Saudi
   - Hotel Makkah (11 pilihan hotel populer dekat Masjidil Haram, kamar Quad/Triple/Double)
   - Hotel Madinah (10 pilihan hotel populer dekat Masjid Nabawi, kamar Quad/Triple/Double)
   - Kereta Cepat Haramain (HHR - Haramain High Speed Railway) rute Jeddah, Makkah, Madinah
   - Transportasi Bus / Armada Lokal (HiAce, Coaster, Mercedes Bus, GMC Yukon VIP)
   - Layanan Mutawwif & Handling Bandara
   - Estimasi Tiket Pesawat PP Internasional
2. **Sticky Total Bar**:
   - Total rombongan, biaya per jamaah, dan estimasi SAR real-time.
   - Tombol instan WhatsApp konsultasi dengan pesan terformat otomatis.
3. **Checklist Persiapan Ibadah (`checklist.html`)**:
   - 4 fase persiapan (Dokumen, Kesehatan, Keuangan, H-3).
   - Indikator progres persentase (0-100%).
   - Simpan checklist ke local storage & cetak PDF.
4. **Sistem Visual Mutawwifmu**:
   - Warna resmi: Royal Navy `#426BAD`, Deep Navy `#1F355A`, Kaaba Gold `#D69E4B`.
   - Typography: Montserrat & Plus Jakarta Sans.
   - Responsif di semua ukuran layar (Mobile 390px, Tablet, Desktop).

## 🛠️ Tech Stack
- HTML5 & Modern Vanilla CSS
- Vanilla JavaScript (ES6+)
- Google Fonts (Montserrat & Plus Jakarta Sans)
